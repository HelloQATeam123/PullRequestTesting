# Shopping Time

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://shopping-time.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
A modern e-commerce platform built with React.js and Firebase.

## Key Features
🛒 Shopping Cart Management
🔍 Product Search & Filtering
💰 Multiple Currency Support
🔐 Secure Firebase Integration

## Technical Implementation
- React.js for frontend
- Firebase for backend services
- Context API for state management
- Responsive design with CSS3

## Getting Started
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```

## Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server on port 3000 |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
