# E-Commerce Shopping Cart 🛒

[![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](https://shopping-cart-demo.netlify.app)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 📝 Description
A modern e-commerce shopping cart built with React, featuring advanced cart management and multi-currency support.

## ✨ Key Features

### Advanced Cart Management
- Real-time cart updates
- Quantity adjustments
- Item removal
- Cart persistence

### Enhanced Shopping Experience
- Product filtering
- Search functionality
- Responsive design
- Product categories

### Multi-Currency Support
- Dynamic currency conversion
- Multiple currency options
- Real-time price updates

### Secure Checkout Process
- Secure payment gateway
- Order confirmation
- Transaction history

## 🏆 Technical Achievements
- Implemented React Context for state management
- Optimized performance with React.memo
- Responsive design using CSS Grid/Flexbox
- Firebase integration for data persistence

## 🚀 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs the app in development mode |
| `npm test` | Launches the test runner |
| `npm run build` | Builds the app for production |
| `npm run eject` | Ejects from Create React App |
