# Shopping Time

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://shopping-time.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 🚀 Overview
A modern e-commerce platform built with React and Firebase.

## ✨ Features

### Shopping Experience
- 🛍️ Browse products by category
- 🔍 Search and filter functionality
- 💰 Multi-currency support
- 🛒 Real-time cart updates

### User Interface
- 📱 Responsive design
- 🎨 Modern, clean interface
- ⚡ Fast loading times
- 🌙 Dark mode support

## 🛠️ Technical Highlights
- React for frontend
- Firebase for backend
- Redux for state management
- Styled Components
- React Router for navigation

## 🏃‍♂️ Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
| `npm run eject` | Ejects CRA configuration |

## 📁 Project Structure
```
src/
  ├── components/     # UI components

  ├── data/          # Static data
  ├── database/      # Firebase config
  ├── routes/        # Application routes
  └── helpers/       # Utility functions
```
