# Shopping Time

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A comprehensive e-commerce platform specializing in women's clothing, featuring over 150 products with customizable attributes and a robust shopping experience.

[View Live Demo](https://shopping-time.vercel.app/)

## Features

- **Product Management**
  - Extensive catalog with 150+ women's clothing items
  - Multiple size and color options per product
  - Detailed product attributes and descriptions

- **Shopping Experience**
  - Intuitive cart management system
  - Real-time cart overlay
  - Category-based filtering
  - Multi-currency support (EUR, GBP, AUD, JPY)

- **Checkout Process**
  - Secure multi-step checkout
  - Form validation
  - Order confirmation system

## Technology Stack

- React.js
- Firebase/Firestore
- React Router
- React Simple Image Slider
- UUID

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/HelloQATeam123/PullRequestTesting.git
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm start
   ```

Visit `http://localhost:3000` to view the application.

## Development Scripts

- `npm start` - Run development server
- `npm test` - Execute test suite
- `npm run build` - Create production build
- `npm run eject` - Eject from Create React App
