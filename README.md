## Overview
Shopping Time is a modern e-commerce platform built with React, offering a seamless shopping experience with advanced features and a user-friendly interface.

## ✨ Key Features
- 🛒 **Cart Management**: Add/remove items, adjust quantities, persistent cart
- 🛍️ **Shopping Experience**: Product categories, detailed views, search functionality
- 💱 **Currency Support**: Multiple currency options with real-time conversion
- 💳 **Checkout Process**: Streamlined checkout with order confirmation

## Development Goals
- Create an intuitive shopping interface
- Implement responsive design principles
- Ensure secure transaction handling
- Optimize performance and loading times

## Quick Start
### Prerequisites
- Node.js (v14+)
- npm/yarn

### Installation
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
cd PullRequestTesting
npm install
npm start
```
