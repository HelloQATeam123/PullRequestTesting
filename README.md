# E-Commerce React App 🛍️

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://your-demo-link.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A modern e-commerce application built with React, featuring product browsing, cart management, and checkout functionality.

## 🚀 Features

- Product catalog with categories
- Shopping cart functionality
- Responsive design
- Firebase integration
- Currency selection
- Order management

## 💻 Technology Stack

| Technology    | Purpose                  |
|--------------|--------------------------|
| React        | Frontend Framework       |
| Firebase     | Backend & Authentication |
| CSS          | Styling                  |

## 📜 Available Scripts

| Command         | Description                |
|----------------|----------------------------|
| `npm start`    | Run development server     |
| `npm test`     | Execute tests             |
| `npm run build`| Create production build    |

## 🗂️ Project Structure

```
src/
  ├── components/     # React components
  ├── core-ui/       # CSS and UI utilities
  ├── data/          # Static data
  ├── database/      # Firebase configuration
  ├── routes/        # Application routes
  └── helpers/       # Helper functions
```

## 🚦 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm start`
4. Open [http://localhost:3000](http://localhost:3000)
