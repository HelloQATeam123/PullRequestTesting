# Shopping Time 🛍️

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://shopping-time.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
A modern e-commerce platform built with React, featuring a responsive design and seamless shopping experience.

## ✨ Key Features
- 🛒 Dynamic shopping cart management
- 💳 Secure checkout process
- 🔍 Product search and filtering
- 📱 Responsive design for all devices
- 🌐 Multi-currency support

## 🚀 Technical Achievements
- Implemented Firebase integration for data management
- Built custom cart overlay system
- Created responsive UI components
- Developed currency conversion functionality

## 💻 Technology Stack
| Category | Technologies |
|----------|-------------|
| Frontend | React.js, CSS3 |
| Backend | Firebase |
| State Management | React Context |
| Deployment | Vercel |

## 🚀 Getting Started
```bash
# Clone repository
```
