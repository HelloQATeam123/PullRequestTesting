## Overview
A modern e-commerce platform built with React, featuring a responsive design and comprehensive shopping functionality.

## Key Features
### Cart Management
- Dynamic cart updates
- Quantity modification
- Item removal
- Persistent cart data

### Shopping Experience
- Product categorization
- Detailed product views
- Image galleries
- Search functionality

### Currency Support
- Multiple currency options
- Real-time price conversion
- Currency preference saving

### Checkout Process
- Streamlined checkout
- Order summary
- Payment integration
- Order confirmation

## Technical Stack
- React 18
- Firebase
- CSS3
- HTML5

## Prerequisites
- Node.js (v14+)
- npm/yarn
- Git

## Installation
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
cd PullRequestTesting
npm install
npm start
```

## Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
| `npm run eject` | Ejects CRA config |

## Dependencies
- React Router
