## Overview 📝
A modern e-commerce application built with React, featuring product browsing, cart management, and checkout functionality.

## Features ✨
- Product catalog with categories
- Shopping cart functionality
- Responsive design
- Firebase integration
- Currency selection

## Tech Stack 🛠️
| Technology | Purpose |
|------------|---------|
| React | Frontend framework |
| Firebase | Backend & Authentication |
| CSS | Styling |

## Scripts 📜
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes tests |
| `npm run build` | Creates production build |

## Installation 💻
1. Clone repository
2. Run `npm install`
3. Start with `npm start`

## Project Structure 📂
- `/src/components` - React components
- `/src/routes` - Application routes
- `/src/assets` - Static assets
- `/src/core-ui` - Core styling
- `/src/database` - Firebase configuration
