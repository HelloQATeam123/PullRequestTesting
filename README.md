# [Shopping Time](https://shopping-time.vercel.app/)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Node.js](https://img.shields.io/badge/Node.js-v14+-green.svg)](https://nodejs.org/)
[![React](https://img.shields.io/badge/React-18+-blue.svg)](https://reactjs.org/)

Shopping Time is a comprehensive e-commerce web application featuring over 150 women's clothing products with customizable attributes including size and color variations. The platform provides a complete shopping experience with advanced cart management, multi-currency support, and a secure checkout process designed for optimal user experience.

## Features

- **Shopping Cart Management**: Add, remove, and modify product quantities with real-time cart updates
- **Product Catalog**: Browse extensive collection with category filtering and detailed product pages
- **Attribute Selection**: Choose product variants including size, color, and other specifications
- **Cart Overlay**: Quick access to cart summary without navigation interruption
- **Multi-Currency Support**: Shop in various currencies including EUR, GBP, AUD, JPY, and more
- **Multi-Step Checkout**: Secure, user-friendly checkout process with form validation
- **Category Filtering**: Efficient product discovery through organized category navigation
- **Responsive Design**: Optimized experience across desktop and mobile devices

## Tech Stack

- **Frontend:** React.js, CSS3, HTML5
- **Backend/Database:** Firebase Firestore
- **Routing:** React Router DOM
- **Package Management:** npm
- **Additional Libraries:** React Simple Image Slider, UUID

## Getting Started

### Prerequisites

- **Node.js** v14 or higher
- **npm** package manager
- Modern web browser with JavaScript enabled

## Installation

1. Clone the repository
   ```bash
   git clone https://github.com/catherineisonline/shopping-time.git
   ```

2. Navigate to project directory
   ```bash
   cd shopping-time
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Configure environment variables
   - Set up Firebase configuration
   - Configure any required API keys

5. Start development server
   ```bash
   npm start
   ```

## Usage

The application will be available at `http://localhost:3000` in development mode. The following scripts are available:

- **`npm start`**: Runs the application in development mode with hot reloading
- **`npm test`**: Launches the test runner in interactive watch mode
- **`npm run build`**: Creates an optimized production build
- **`npm run eject`**: Ejects from Create React App (irreversible operation)

Navigate through the application to browse products, add items to your cart, and complete the checkout process. The application supports real-time updates and maintains state across sessions.
