# Shopping Time 🛍️

[![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](https://shopping-time.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A modern e-commerce platform built with React.js and Firebase.

## 🚀 Features

- Product catalog with categories
- Shopping cart functionality
- User authentication
- Responsive design
- Order tracking
- Multiple currency support

## 🛠️ Built With

- React.js
- Firebase
- Redux
- Styled Components

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```

## 📝 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
| `npm run eject` | Ejects CRA configuration |
