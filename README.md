# E-Commerce React App 🛍️ [![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](https://e-commerce-react-app.vercel.app/) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A modern e-commerce web application built with React.js and Firebase.

## 🚀 Features
- Product catalog with categories
- Shopping cart functionality
- User authentication
- Responsive design
- Order processing

## 🛠️ Tech Stack
| Technology | Purpose |
|------------|---------|
| React.js | Frontend framework |
| Firebase | Backend & Authentication |
| CSS3 | Styling |
| Vercel | Deployment |

## 📦 Installation & Setup
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```
