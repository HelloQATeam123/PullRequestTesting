# [Shopping Time](https://shopping-time.vercel.app/)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Node.js](https://img.shields.io/badge/Node.js-v14+-green.svg)](https://nodejs.org/)
[![React](https://img.shields.io/badge/React-18+-blue.svg)](https://reactjs.org/)

Shopping Time is a modern e-commerce web application featuring over 150 women's clothing products with comprehensive customization options. Built with React and Firebase, this application provides a seamless shopping experience with dynamic product attributes, cart management, and multi-currency support.

## Features

- **Shopping Cart Management**
  - Add and remove products with ease
  - Adjust product quantities dynamically
  - Real-time cart overlay for quick review
  - Detailed product attributes display (size, color, etc.)

- **Product Catalog**
  - Category-based product filtering
  - Multiple product attribute selection (size, color)
  - Comprehensive product pages with detailed information
  - Seamless shopping experience across category and product pages

- **Checkout Process**
  - Multi-step checkout workflow
  - Form validation for accurate order processing
  - Secure transaction handling

- **Currency Support**
  - Multiple currency options (EUR, GBP, AUD, JPY, and more)
  - Dynamic currency conversion
  - Global customer support

## Tech Stack

- **Frontend:** React, CSS, React Router
- **Backend/Database:** Firebase, Firestore
- **Package Management:** npm
- **Additional Libraries:** React Simple Image Slider, UUID

## Getting Started

### Prerequisites

- Node.js v14 or higher
- npm package manager
- Firebase account for database configuration

## Installation

1. Clone the repository
   ```bash
   git clone https://github.com/HelloQATeam123/PullRequestTesting.git
   ```

2. Navigate to project directory
   ```bash
   cd PullRequestTesting
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Configure environment variables
   - Set up Firebase configuration
   - Add necessary API keys

5. Start development server
   ```bash
   npm start
   ```

## Usage

### Development Mode
```bash
npm start
```
Runs the application in development mode. Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will reload automatically when you make changes.

### Testing
```bash
npm test
```
Launches the test runner in interactive watch mode.

### Production Build
```bash
npm run build
```
Builds the application for production to the `build` folder. The build is optimized for best performance with minified files and hashed filenames.

### Advanced Configuration
```bash
npm run eject
```
**Note: This is a one-way operation.** Ejects the application from Create React App configuration, giving you full control over webpack, Babel, ESLint, and other build tools.
