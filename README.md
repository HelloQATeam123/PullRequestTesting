# Shopping Time 🛍️

[![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](https://shopping-time.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A modern e-commerce web application built with React.js and Firebase.

![Preview](src/assets/images/preview.png)

## ✨ Key Features
- 🛒 Shopping cart functionality
- 💳 Secure checkout process
- 🔍 Product search and filtering
- 📱 Responsive design
- 🌐 Multiple currency support

## 🏆 Technical Achievements
- ✓ Custom React hooks
- ✓ Context API implementation
- ✓ Firebase integration
- ✓ Responsive CSS Grid/Flexbox
- ✓ Modern ES6+ JavaScript

## 🛠️ Technology Stack
- React.js
- Firebase
- Context API
- CSS Modules
- Jest for testing

## 🚀 Quick Start
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```

## 📜 Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
| `npm run eject` | Ejects CRA configuration |
