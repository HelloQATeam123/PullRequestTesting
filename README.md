## 📋 Overview
Modern e-commerce application built with React and Firebase.

## ✨ Key Features
- Product catalog with categories
- Shopping cart functionality
- User authentication
- Order processing
- Responsive design

## 🛠️ Technical Stack
- React
- Firebase
- CSS3
- JavaScript ES6+

## 🚀 Getting Started
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```

## 📁 Project Structure
```
src/
├── components/     # React components
├── core-ui/       # CSS and styling
├── data/          # Product data
├── database/      # Firebase config
├── routes/        # Application routes
└── helpers/       # Utility functions
```

## 📦 Dependencies
- react
- firebase
- react-router-dom
