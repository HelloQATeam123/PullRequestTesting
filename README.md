# E-Commerce React Application 🛍️

A modern e-commerce application built with React and Firebase.

## Prerequisites 🔧
- Node.js (v14 or higher)
- npm or yarn
- Firebase account

## Quick Start 🚀
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
cd PullRequestTesting
npm install
npm start
```

## Available Scripts 📜
| Command | Description |
|---------|-------------|
| `npm start` | Runs the app in development mode |
| `npm test` | Launches the test runner |
| `npm run build` | Builds the app for production |

## Core Libraries 📚
| Library | Purpose |
|---------|----------|
| React | Frontend framework |
| Firebase | Backend services |
| React Router | Navigation |

## Technical Details 💻
- Single page application using React
- State management with React Context
- Firebase Authentication and Firestore
- Responsive design with CSS Grid/Flexbox
- Component-based architecture

## Project Structure 📁
- `/src/components` - Reusable UI components
- `/src/routes` - Page components and routing
- `/src/core-ui` - Global styles and UI utilities
- `/src/database` - Firebase configuration
- `/src/helpers` - Utility functions
