# E-Commerce React App 🛍️

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://your-demo-link.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A modern e-commerce application built with React, featuring a responsive design, cart management, and secure checkout process.

## 🚀 Features

- Product catalog with categories
- Shopping cart functionality
- Real-time currency conversion
- Responsive design for all devices
- Firebase integration for data storage
- Secure checkout process

## 🛠️ Installation

```bash
npm install
npm start
```

## 📜 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs the app in development mode |
| `npm test` | Launches the test runner |
| `npm run build` | Builds the app for production |

## 🔧 Technical Stack
