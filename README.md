## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm start
```

## 📋 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
