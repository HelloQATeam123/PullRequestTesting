# E-Commerce React App 🛍️

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://your-demo-link.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A modern e-commerce application built with React, featuring product browsing, cart management, and checkout functionality.

## Features ✨

- Product catalog with categories
- Shopping cart functionality  
- Quantity adjustment
- Responsive design
- Firebase integration

## Project Structure 📁

```
src/
├── components/
│   ├── AddToCartButton.js
│   ├── ChangeCartItemQuantity.js
│   └── SuccessMessage.js
├── core-ui/
├── data/
└── routes/
```

## Scripts 🚀

| Command | Description |
|---------|------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |

## Dependencies 📦

| Package | Version |
|---------|---------|
| react | ^17.0.2 |
| firebase | ^9.0.0 |

## Getting Started 🚀

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm start`
