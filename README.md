## 🚀 Overview
Modern e-commerce application built with React featuring product catalog, cart management, and checkout functionality.

## ✨ Features
- Product catalog with categories
- Cart management
- Currency selection
- Responsive design
- Firebase integration
- Order processing

## 🛠 Technical Stack
- React 18
- Firebase
- CSS3
- React Router

## 📦 Installation
```bash
npm install
npm start
```

## 📜 Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes tests |
| `npm run build` | Creates production build |
