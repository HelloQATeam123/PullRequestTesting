# PullRequestTesting

[![Demo](https://img.shields.io/badge/demo-online-green.svg)](https://pullrequesttesting.com)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 🚀 Overview
A React-based e-commerce application for testing pull request workflows.

## ✨ Features
- Product catalog with filtering
- Shopping cart functionality 
- Checkout process
- Order management
- Responsive design

## 🛠️ Installation
```bash
npm install
npm start
```

## 📜 Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
