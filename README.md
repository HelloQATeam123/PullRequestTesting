# E-Commerce React Application

A modern e-commerce application built with React, featuring product browsing, cart management, and checkout functionality.

![Application Preview](src/assets/images/preview.png)

## 🚀 Key Features
- Product catalog with filtering and search
- Shopping cart with real-time updates
- Secure checkout process
- Responsive design for all devices
- Currency conversion support

## 🛠 Technical Implementation
- React-based frontend architecture
- Firebase backend integration
- State management with Context API
- Custom hooks for business logic
- Component-based UI structure

## 🏁 Getting Started
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```

## 📜 Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
| `npm run eject` | Ejects CRA configuration |
