# [Shopping Time](https://shopping-time.vercel.app/)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Node.js](https://img.shields.io/badge/Node.js-v14+-green.svg)](https://nodejs.org/)
[![React](https://img.shields.io/badge/React-18+-blue.svg)](https://reactjs.org/)

Shopping Time is a modern e-commerce web application featuring over 150 women's clothing products with comprehensive customization options. Built with React.js and Firebase, this application provides a complete online shopping experience with dynamic product attributes, shopping cart management, multi-currency support, and a streamlined checkout process.

## Features

- **Shopping Cart Management**
  - Add and remove products with ease
  - Adjust product quantities dynamically
  - Real-time cart overlay with item summaries
  - Detailed product attributes display (size, color, etc.)

- **Product Catalog**
  - 150+ women's clothing products
  - Category-based filtering system
  - Multiple product attributes (size, color variations)
  - Seamless shopping from category and product pages

- **Multi-Currency Support**
  - Support for multiple currencies (EUR, GBP, AUD, JPY, and more)
  - Dynamic currency conversion
  - Localized pricing display

- **Secure Checkout Process**
  - Multi-step checkout workflow
  - Comprehensive form validations
  - Error prevention and user guidance
  - Secure order processing

- **User Experience**
  - Responsive design for all devices
  - Intuitive navigation and interface
  - Real-time updates and feedback
  - Attribute validation before cart addition

## Tech Stack

- **Frontend:** React.js, CSS3, HTML5
- **Backend/Database:** Firebase, Firestore
- **Routing:** React Router
- **Package Management:** npm
- **Additional Libraries:** React Simple Image Slider, UUID

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (Node Package Manager)
- Modern web browser
- Firebase account (for backend services)

## Installation

1. Clone the repository
   ```bash
   git clone https://github.com/catherineisonline/shopping-time.git
   ```

2. Navigate to project directory
   ```bash
   cd shopping-time
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Configure environment variables
   - Set up Firebase configuration
   - Add necessary API keys and environment variables

5. Start development server
   ```bash
   npm start
   ```

## Usage

### Development Mode
Run the application in development mode:
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will reload automatically when you make changes.

### Testing
Launch the test runner in interactive watch mode:
```bash
npm test
```

### Production Build
Build the app for production:
```bash
npm run build
```
This creates an optimized production build in the `build` folder with minified files and hashed filenames.

### Additional Scripts
- `npm run eject` - Ejects from Create React App (one-way operation)
