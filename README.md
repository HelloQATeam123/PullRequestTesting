# Shopping Time 🛍️

[![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](https://shopping-time-demo.web.app)

## 📝 Description
A modern e-commerce platform built with React, featuring a responsive design and seamless shopping experience.

## 🚀 Technical Stack
| Technology | Purpose |
|------------|---------|
| React.js | Frontend Framework |
| Firebase | Backend & Hosting |
| CSS3 | Styling |
| React Router | Navigation |

## 🛠️ Installation
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```
