# E-Commerce React App 🛍️

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://your-demo-link.com)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![React Version](https://img.shields.io/badge/react-18.2.0-61dafb.svg)](package.json)

A modern e-commerce application built with React, featuring a responsive design and seamless shopping experience.

## ✨ Features

- 🛒 Shopping cart functionality
- 💳 Secure checkout process
- 🔍 Product search and filtering
- 📱 Responsive design for all devices
- 🌐 Multiple currency support
- 🎨 Dynamic product attributes

## 🚀 Tech Stack

- React 18
- Firebase
- CSS3
- HTML5

## 📋 Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## 🛠️ Installation

1. Clone the repository
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```
