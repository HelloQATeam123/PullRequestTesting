# 🛍️ E-Commerce Shopping Cart

## 📝 Overview
Modern e-commerce shopping cart implementation with React.

## ✨ Features

### 🛒 Cart Management
- Add/remove items
- Adjust quantities
- Save cart state

### 🛍️ Shopping Experience
- Product browsing
- Category filtering
- Search functionality

### 💳 Checkout Process
- Order summary
- Payment integration
- Order confirmation

## 🔧 Technical Implementation
- React.js frontend
- Firebase backend
- Responsive design

## 🚀 Getting Started

### Prerequisites
- Node.js (v14+)
- npm/yarn

### Installation
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
cd PullRequestTesting
npm install
```

### Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm build` | Creates production build |
