# PullRequestTesting

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://pullrequesttesting.web.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> A React-based e-commerce application demonstrating modern web development practices and pull request workflows.

## 🚀 Quick Start

```bash
npm install
npm start
```

## 🛠️ Built With
- React
- Firebase
- CSS3

## 📦 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |

## 🔧 Dependencies

| Package | Version |
|---------|----------|
| react | ^17.0.2 |
| firebase | ^9.0.0 |
