# E-Commerce React App 🛍️

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://your-demo-link.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A modern e-commerce application built with React, featuring product browsing, cart management, and checkout functionality.

## 🚀 Features

- Product catalog with categories
- Shopping cart functionality
- Currency selection
- Responsive design
- Firebase integration

## 🛠️ Technical Implementation

- React for UI components
- Firebase for backend services
- Custom CSS for styling
- Component-based architecture

## 📦 Project Structure

```
src/
  ├── components/      # Reusable UI components
  ├── core-ui/        # Core styling and UI utilities
  ├── data/           # Static data and configurations
  ├── database/       # Firebase configuration
  ├── helpers/        # Utility functions
  └── routes/         # Application routes
```

## 🔧 Prerequisites

- Node.js (v14+)
- npm or yarn

## 📥 Installation

1. Clone the repository
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
```

2. Install dependencies
```bash
npm install
```

3. Start development server
```bash
npm start
```

## 📝 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm build` | Creates production build |
