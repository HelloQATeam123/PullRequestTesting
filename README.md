## Overview

Shopping Time is a modern, responsive e-commerce platform specializing in women's fashion. Built with React and Firebase, it features a comprehensive catalog of 150+ clothing items with dynamic attribute selection, multi-currency support, and an intuitive shopping cart experience.

## ✨ Key Features

### 🛒 Cart Management
- **Add/Remove Products**: Seamlessly add items to cart with one-click functionality
- **Quantity Control**: Adjust product quantities directly from cart or overlay
- **Cart Overlay**: Real-time cart summary without page navigation
- **Product Details**: Complete attribute information (size, color) displayed in cart

### 🛍️ Shopping Experience
- **Category Filtering**: Browse products by organized categories
- **Flexible Shopping**: Add to cart from both category and product detail pages
- **Attribute Validation**: Required attribute selection prevents ordering errors
- **Product Catalog**: 150+ women's clothing items with multiple variants

### 💰 Multi-Currency Support
- **Global Accessibility**: Support for EUR, GBP, AUD, JPY, and more
- **Dynamic Pricing**: Real-time currency conversion throughout the platform

### 🔒 Secure Checkout
- **Multi-Step Process**: Guided checkout flow for optimal user experience
- **Form Validation**: Comprehensive input validation to ensure data accuracy
- **Error Prevention**: Built-in safeguards against incomplete orders

## 🛠️ Technical Implementation

### Architecture & Development Goals
- **React Evolution**: Implemented using Class components, then refactored to modern React Hooks
- **State Management**: Complex cart logic with attribute selection and validation
- **Form Handling**: Comprehensive validation system for checkout process
- **External Storage**: Firebase integration for persistent data management

### Tech Stack
- **Frontend**: React 18.x with modern hooks and functional components
- **Backend**: Firebase Firestore for data persistence
- **Routing**: React Router for seamless navigation
- **Styling**: Responsive CSS with mobile-first approach
- **Build Tool**: Create React App for optimized development workflow

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/HelloQATeam123/PullRequestTesting.git
   cd PullRequestTesting
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.

## 📜 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs the app in development mode on [http://localhost:3000](http://localhost:3000) |
| `npm test` | Launches the test runner in interactive watch mode |
| `npm run build` | Builds the app for production to the `build` folder |
| `npm run eject` | **One-way operation** - Ejects from Create React App configuration |

### Production Build
The build command creates an optimized production build with:
- Minified and bundled code
- Hashed filenames for caching
- Optimized performance
- Ready for deployment

For more information about deployment, see the [Create React App deployment documentation](https://facebook.github.io/create-react-app/docs/deployment).
