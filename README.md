# Shopping Time

[![Live Demo](https://img.shields.io/badge/Live%20Demo-View%20Site-blue)](https://shopping-time.vercel.app/)

A comprehensive e-commerce platform featuring 150+ women's clothing products with advanced filtering, cart management, and multi-currency support.

## Features

### Shopping Experience
- Product catalog with 150+ women's clothing items
- Advanced filtering by categories
- Product attribute selection (size, color)
- Multi-currency support (EUR, GBP, AUD, JPY, etc.)

### Cart Management
- Add/remove products
- Quantity adjustment
- Cart overlay with product summary
- Detailed product attributes display

### Checkout Process
- Multi-step secure checkout
- Form validation
- Order confirmation

## Installation

1. Clone the repository
   ```bash
   git clone https://github.com/HelloQATeam123/PullRequestTesting.git
   ```
2. Install dependencies
   ```bash
   npm install
   ```
3. Start the development server
   ```bash
   npm start
   ```

## Technology Stack

- React.js
- React Router
- React Simple Image Slider
- UUID
- Firebase/Firestore

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Launches the test runner in the interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.
