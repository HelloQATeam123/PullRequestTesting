## Overview 🎯
Modern e-commerce application built with React featuring product catalog, cart management, and checkout functionality.

## Features ✨
- Product catalog with categories
- Shopping cart functionality
- Currency selection
- Responsive design
- Order management
- Firebase integration

## Tech Stack 💻
| Technology | Version |
|------------|---------|
| React      | ^17.0.2 |
| Firebase   | ^9.0.0  |

## Scripts 🔧
| Command | Description |
|---------|-------------|
| `npm start` | Run development server |
| `npm test` | Execute tests |
| `npm build` | Build for production |

## Project Structure 📁
```
src/
├── components/     # React components
├── core-ui/       # Styling and UI elements
├── data/          # Static data
├── database/      # Firebase configuration
├── routes/        # Application routes
└── helpers/       # Utility functions
```

## Installation 🚀
1. Clone repository
2. Run `npm install`
3. Start with `npm start`
