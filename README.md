# PullRequestTesting

[![React](https://img.shields.io/badge/React-18+-blue)](https://reactjs.org/)
[![Firebase](https://img.shields.io/badge/Firebase-integrated-orange)](https://firebase.google.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A React-based e-commerce testing platform integrated with Firebase.

## Features
- Shopping cart functionality
- Multi-currency support
- Product catalog management
- Firebase integration
- Responsive design

## Installation
```bash
npm install
```

## Usage
```bash
npm start
```
Runs the app in development mode at [http://localhost:3000](http://localhost:3000)

## Project Structure
```
src/
  ├── components/     # Reusable UI components
  ├── core-ui/       # Core styling and UI elements
  ├── data/          # Product data and constants
  ├── database/      # Firebase configuration
  ├── routes/        # Application routes
  └── helpers/       # Utility functions
```

## Testing
```bash
npm test
```
