# E-Commerce React App

[![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](https://your-demo-link.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A modern e-commerce application built with React.js featuring product management, cart functionality, and checkout process.

## ✨ Features

🛍️ **Shopping Experience**
- Product browsing and search
- Category filtering
- Detailed product views

🛒 **Cart Management**
- Add/remove items
- Quantity adjustment
- Cart overlay preview

💳 **Checkout Process**
- Secure checkout flow
- Order summary
- Payment integration

## 🚀 Technology Stack

- React.js
- Firebase Database
- CSS3 (Custom styling)
- Modern JavaScript (ES6+)

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```

## 🛠️ Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
