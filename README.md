# Shopping Time 🛍️

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://shopping-time.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
A modern e-commerce platform built with React.js and Firebase.

## Key Features
🛒 Shopping cart functionality
🔍 Product search and filtering
💰 Multiple currency support
🔐 Secure checkout process

## Technical Achievements
- Responsive design for all devices
- Real-time cart updates
- Firebase integration
- Component-based architecture

## Technology Stack
- React.js
- Firebase
- CSS3
- HTML5

## Project Structure
```
src/
├── components/       # Reusable UI components
├── core-ui/         # Core styling and UI elements
├── data/           # Static data and configurations
├── database/       # Firebase configuration
├── helpers/        # Utility functions
└── routes/         # Application routes
```

## Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm start`

## Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
