# E-Commerce React App 🛍️

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://your-demo-link.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A modern e-commerce application built with React, featuring product browsing, cart management, and checkout functionality.

## 🚀 Features

- Product catalog with categories
- Shopping cart functionality
- Quantity adjustment
- Responsive design
- Firebase integration

## 🛠️ Technology Stack

| Technology | Purpose |
|------------|---------|
| React      | Frontend framework |
| Firebase   | Backend & Authentication |
| CSS        | Styling |

## 📦 Installation

```bash
npm install
npm start
```

## 🔧 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes tests |
| `npm run build` | Creates production build |

## 📁 Project Structure

```
src/
├── components/     # React components
├── core-ui/       # CSS and UI utilities
├── data/          # Static data
├── database/      # Firebase configuration
├── routes/        # Application routes
└── helpers/       # Helper functions
```
