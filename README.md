# Shopping Time 🛒

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://shopping-time.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview
A modern e-commerce platform built with React and Firebase, featuring real-time cart updates and secure checkout.

## Key Features 🔍
- Dynamic product catalog
- Real-time cart management
- Multiple currency support
- Secure checkout process
- Responsive design

## Technical Achievements 💰
- Firebase integration for data persistence
- Real-time cart synchronization
- Multi-currency conversion
- Optimized performance

## Technology Stack 🔐
- React.js
- Firebase
- Context API
- CSS Modules

## Installation & Setup
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
cd PullRequestTesting
npm install
npm start
```
