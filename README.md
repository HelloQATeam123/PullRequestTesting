# Shopping Time

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://shopping-time.vercel.app/)
[![React](https://img.shields.io/badge/React-18+-blue)](https://reactjs.org/)
[![Firebase](https://img.shields.io/badge/Firebase-integrated-orange)](https://firebase.google.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A modern e-commerce platform built with React and Firebase.

## 🚀 Features

- Product catalog with categories
- Shopping cart functionality
- User authentication
- Order processing
- Responsive design

## 🛠️ Tech Stack

- React 18+
- Firebase
- CSS3
- HTML5

## 📦 Installation

```bash
npm install
npm start
```

## 🔧 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |

## 📚 Project Structure

```
src/
  ├── components/    # Reusable components
  ├── core-ui/      # Core styling
  ├── data/         # Data files
  ├── database/     # Firebase configuration
  ├── routes/       # Application routes
  └── helpers/      # Utility functions
```
