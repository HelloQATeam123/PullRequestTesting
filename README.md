# Shopping Time

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://pullrequesttesting.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![React](https://img.shields.io/badge/React-18.x-blue)](https://reactjs.org/)

A modern, responsive e-commerce platform built with React, featuring a comprehensive catalog of women's clothing with advanced shopping cart functionality and multi-currency support.

## 🚀 Live Demo

Visit the live application: [Shopping Time](https://pullrequesttesting.vercel.app/)

## 📋 Overview

Shopping Time is a full-featured e-commerce web application that showcases modern React development practices. The platform offers an extensive collection of over 150 women's clothing items with customizable attributes, intelligent cart management, and a seamless checkout experience.

## ✨ Key Features

### 🛒 Advanced Cart Management
- **Dynamic Product Management**: Add, remove, and modify products with real-time updates
- **Quantity Control**: Flexible quantity adjustment with instant cart recalculation
- **Cart Overlay**: Non-intrusive cart preview without navigation disruption
- **Attribute Tracking**: Comprehensive product details including size, color, and specifications

### 🔍 Enhanced Shopping Experience
- **Category Filtering**: Intuitive product categorization and filtering system
- **Multi-page Shopping**: Seamless product addition from both category and detail pages
- **Attribute Validation**: Mandatory attribute selection to ensure order accuracy
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices

### 💰 Multi-Currency Support
- **Global Currency Options**: Support for EUR, GBP, AUD, JPY, and additional currencies
- **Real-time Conversion**: Dynamic price updates based on selected currency
- **Localized Experience**: Currency formatting appropriate to user selection

### 🔐 Secure Checkout Process
- **Multi-step Workflow**: Guided checkout process with clear progress indicators
- **Form Validation**: Comprehensive client-side validation for data integrity
- **Error Handling**: User-friendly error messages and recovery options

## 🛠 Technical Implementation

### Architecture & Development Goals
- **Component Evolution**: Implemented using React Class components, then refactored to modern Hooks
- **State Management**: Custom cart logic with persistent state management
- **Form Handling**: Robust validation system with user feedback
- **External Integration**: Firebase integration for data persistence and management

### Technology Stack
- **Frontend**: React 18.x with modern Hooks
- **Routing**: React Router for SPA navigation
- **Database**: Firebase Firestore for data persistence
- **Styling**: Custom CSS with responsive design principles
- **Build Tool**: Create React App for development and production builds

## 🚀 Getting Started

### Prerequisites
- Node.js (version 14.x or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/HelloQATeam123/PullRequestTesting.git
   cd PullRequestTesting
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

## 📜 Available Scripts

### Development
```bash
npm start          # Start development server
npm test           # Run test suite in watch mode
npm run build      # Create production build
npm run eject      # Eject from Create React App (irreversible)
```

### Production Build
The `npm run build` command creates an optimized production build in the `build` folder, with minified files and hashed filenames for optimal caching.
