# [Shopping Time](https://shopping-time.vercel.app/)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Node.js](https://img.shields.io/badge/Node.js-v14+-green.svg)](https://nodejs.org/)
[![React](https://img.shields.io/badge/React-18+-blue.svg)](https://reactjs.org/)

Shopping Time is a modern e-commerce web application featuring over 150 women's clothing products with comprehensive customization options. Built with React and Firebase, this application provides a complete shopping experience with dynamic product attributes, cart management, multi-currency support, and a streamlined checkout process.

## Features

- **Shopping Cart Management**
  - Add and remove products with ease
  - Adjust product quantities dynamically
  - Real-time cart overlay for quick review
  - Detailed product attributes display (size, color, etc.)

- **Product Catalog**
  - Category-based product filtering
  - Comprehensive product pages with multiple attributes
  - Size and color selection with validation
  - Seamless shopping experience across category and product pages

- **Multi-Currency Support**
  - Support for multiple currencies (EUR, GBP, AUD, JPY, and more)
  - Dynamic currency conversion
  - Localized pricing display

- **Secure Checkout Process**
  - Multi-step checkout workflow
  - Form validation for accurate order processing
  - User-friendly interface design

## Tech Stack

- **Frontend:** React, CSS, React Router
- **Backend/Database:** Firebase, Firestore
- **Package Management:** npm
- **Additional Libraries:** React Simple Image Slider, UUID

## Getting Started

### Prerequisites

- Node.js v14 or higher
- npm package manager
- Firebase account for database configuration

## Installation

1. Clone the repository
   ```bash
   git clone https://github.com/HelloQATeam123/PullRequestTesting.git
   ```

2. Navigate to project directory
   ```bash
   cd PullRequestTesting
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Configure environment variables
   - Set up Firebase configuration
   - Add necessary API keys

5. Start development server
   ```bash
   npm start
   ```

## Usage

### Development Mode
Run the application in development mode:
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) to view it in your browser. The page will reload automatically when you make changes.

### Testing
Launch the test runner in interactive watch mode:
```bash
npm test
```

### Production Build
Build the application for production:
```bash
npm run build
```
This creates an optimized build in the `build` folder, ready for deployment.
