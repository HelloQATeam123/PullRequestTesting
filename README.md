# Shopping Time

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A comprehensive e-commerce platform specializing in women's clothing, featuring over 150 products with customizable attributes and a robust shopping experience.

[View Live Demo](https://shopping-time.vercel.app/)

## Overview

Shopping Time provides a feature-rich online shopping experience with advanced product management, multi-currency support, and a secure checkout process.

## Key Features

- **Product Management**
  - Extensive catalog with 150+ women's clothing items
  - Multiple size and color options
  - Detailed product attributes and descriptions

- **Shopping Experience**
  - Intuitive cart management system
  - Real-time cart overlay
  - Category-based filtering
  - Multi-currency support (EUR, GBP, AUD, JPY)

- **Checkout Process**
  - Multi-step secure checkout
  - Form validation
  - Order tracking

## Technology Stack

- React.js
- Firebase/Firestore
- React Router
- React Simple Image Slider
- UUID

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

## Available Scripts

- `npm start` - Runs the development server
- `npm test` - Executes test suite
- `npm run build` - Creates production build
