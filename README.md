# E-Commerce React App 🛍️

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://e-commerce-react-app.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview 📝
A modern e-commerce web application built with React, featuring a responsive design and seamless shopping experience.

## Features ✨
- 🛒 Shopping cart functionality
- 💳 Secure checkout process
- 🔍 Product search and filtering
- 📱 Responsive design
- 🌐 Multiple currency support
- 🔐 Firebase authentication

## Technology Stack 🛠️
- React.js
- Firebase
- CSS3
- HTML5

## Scripts 📜
| Command | Description |
|---------|-------------|
| `npm start` | Run development server |
| `npm test` | Run test suite |
| `npm run build` | Build for production |

## Dependencies 📦
| Package | Version |
