## 🚀 Getting Started

### Prerequisites
```bash
node >= 14.0.0
npm >= 6.14.0
```

### Installation
```bash
git clone https://github.com/HelloQATeam123/PullRequestTesting.git
cd PullRequestTesting
npm install
npm start
```
