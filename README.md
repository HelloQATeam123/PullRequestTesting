## Features

### Shopping Experience
- Product catalog with 150+ women's clothing items
- Multi-attribute selection (size, color)
- Category-based filtering
- Dynamic currency conversion (EUR, GBP, AUD, JPY)

### Cart Management
- Add/remove products
- Quantity adjustment
- Real-time cart overlay
- Attribute tracking

### Checkout Process
- Multi-step secure checkout
- Form validation
- Firebase data persistence

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation
1. Clone the repository
   ```bash
   git clone https://github.com/HelloQATeam123/PullRequestTesting.git
   ```
2. Install dependencies
   ```bash
   npm install
   ```
3. Start the development server
   ```bash
   npm start
   ```
