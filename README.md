# PullRequestTesting

An e-commerce React application with product catalog, cart functionality, and checkout process.

## Features
- Product catalog browsing
- Shopping cart management
- Checkout process
- Firebase integration
- Responsive design

## Setup
1. Clone the repository
2. Run `npm install`
3. Run `npm start`

## Project Structure
- `/public` - Static assets
- `/src`
  - `/assets` - Images and media files
  - `/components` - React components
  - `/core-ui` - CSS styles
  - `/data` - Product data
  - `/database` - Firebase configuration
  - `/routes` - Application routes
