## 🚀 About
React-based e-commerce application with cart functionality and product management.

## 💻 Tech Stack
- React
- Firebase
- CSS3
- JavaScript

## 📋 Prerequisites
- Node.js (v14+)
- npm or yarn

## 🔧 Installation
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```

## 📁 Project Structure
```
src/
├── components/     # React components
├── core-ui/       # CSS styles
├── data/          # Data files
├── database/      # Firebase config
├── routes/        # Application routes
└── assets/        # Static assets
```

## 📜 Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm build` | Creates production build |
