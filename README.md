## Overview

Shopping Time is a modern e-commerce web application featuring over 150 women's clothing products with comprehensive customization options. Built with React, this platform provides a seamless shopping experience with advanced cart management, multi-currency support, and secure checkout functionality.

## Features
- 🛍️ Product catalog with 150+ items
- 🔍 Advanced filtering and search
- 🛒 Cart management system
- 💰 Multi-currency support
- 🔒 Secure checkout process
- 📱 Responsive design

## Tech Stack
- React
- Firebase
- CSS3
- HTML5

## Project Structure
```
src/
├── components/      # Reusable UI components
├── core-ui/        # Core styling and UI elements
├── data/           # Product data and constants
├── database/       # Firebase configuration
├── routes/         # Application routes
└── assets/         # Images and static assets
```

## Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm start`
