# PullRequestTesting [![Live Demo](https://img.shields.io/badge/demo-online-green.svg)](https://pullrequesttesting.netlify.app) [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

React-based e-commerce application for testing pull requests.

## 🚀 Technical Stack
- React
- Firebase
- CSS3

## ⚙️ Prerequisites
- Node.js (v14+)
- npm/yarn

## 📦 Installation
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```

## 📂 Project Structure
```
src/
├── components/     # React components
├── core-ui/       # CSS styles
├── data/          # Static data
├── database/      # Firebase config
├── routes/        # Application routes
└── assets/        # Images and media
```

## 📝 Available Scripts
| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm build` | Creates production build |
