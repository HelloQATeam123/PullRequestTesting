# Shopping Time

[![Live Demo](https://img.shields.io/badge/demo-live-brightgreen)](https://shopping-time.vercel.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Overview

Shopping Time is a modern e-commerce web application featuring over 150 women's clothing products with comprehensive customization options. Built with React, it provides a seamless shopping experience with dynamic product attributes, cart management, and multi-currency support.

**🔗 [Live Demo](https://shopping-time.vercel.app/)**

## Key Features

### 🛒 **Cart Management**
- **Add/Remove Products**: Intuitive product management with one-click add/remove functionality
- **Quantity Control**: Flexible quantity adjustment for all cart items
- **Cart Overlay**: Real-time cart preview without page navigation
- **Product Details**: Complete attribute information (size, color, etc.) displayed in cart

### 💰 **Multi-Currency Support**
- USD, EUR, JPY, and GBP support
- Real-time currency conversion
- Persistent currency selection

### 🎨 **Product Customization**
- Multiple size options
- Color variants
- Quantity selection
- Image galleries

## Technical Architecture

- **Frontend**: React.js
- **State Management**: Context API
- **Routing**: React Router v6
- **Styling**: CSS Modules
- **Database**: Firebase
- **Deployment**: Vercel
