## 🛒 Overview
A modern e-commerce platform built with React.

## 🔍 Features
- Product catalog with categories
- Shopping cart functionality
- Secure checkout process
- Responsive design

## 💻 Technology Stack
### Core Technologies
- React
- Firebase
- CSS3

### Dependencies
- react-router-dom
- firebase
- @testing-library/react

## 🚀 Getting Started
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```
