# PullRequestTesting 

[![Live Demo](https://img.shields.io/badge/demo-live-green.svg)](https://pullrequesttesting.netlify.app)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 📋 About
React-based e-commerce application for testing pull request workflows.

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm

### Installation
```bash
npm install
npm start
```

## 📁 Project Structure
```
src/
  ├── components/     # React components
  ├── core-ui/       # CSS and styling
  ├── data/          # Data files
  ├── database/      # Firebase configuration
  ├── routes/        # Application routes
  └── assets/        # Images and static files
```

## 📜 Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Runs development server |
| `npm test` | Executes test suite |
| `npm run build` | Creates production build |
| `npm run eject` | Ejects CRA configuration |
