## 🛍️ Overview
A modern e-commerce platform built with React, featuring a responsive design and seamless shopping experience.

![App Preview](src/assets/images/preview.png)

## ✨ Key Features
- 🛒 Shopping cart management
- 💳 Secure checkout process
- 🔍 Product search and filtering
- 📱 Responsive design
- 🌐 Multi-currency support

## 🔧 Technical Implementation
Built using React with a focus on component reusability and state management.

## 🚀 Getting Started
```bash
# Clone repository
git clone https://github.com/HelloQATeam123/PullRequestTesting.git

# Install dependencies
npm install

# Start development server
npm start
```

## 📜 Available Scripts
